## Comment utiliser le notebook de reprise

Tu n'as **jamais** besoin d'avoir réussi l'exercice précédent pour suivre
celui-ci. Ouvre `reprise.ipynb`, exécute les cellules du haut, descends
jusqu'aux blocs `# ✏️ À TOI DE JOUER`.

## Bloqué ?

Colle **le message d'erreur complet en texte** (pas une capture) dans le
salon `#sos-erreurs`. La dernière ligne d'un traceback dit toujours ce qui
ne va pas.
