## Les outils, en bref

**1. Google Classroom — le cœur du cours**
C'est là que vous trouverez les supports, les corrigés et les devoirs, et
c'est là que vous poserez vos questions entre les séances.
👉 Rejoindre la classe : **[COLLER LE LIEN D'INVITATION]**
Un conseil : épinglez l'onglet dans votre navigateur. Vous y reviendrez chaque
semaine, et c'est là que tombent les devoirs.

**2. Google Meet — les séances en direct**
Le lien se trouve dans Classroom et il ne change jamais. Rien à installer :
tout se passe dans le navigateur.

**3. Google Colab — pour écrire et exécuter du code**
Vous codez directement depuis votre navigateur, sans rien installer sur votre
machine. C'est ce que nous utiliserons pendant les premières séances, le temps
que chacun trouve ses marques.
👉 L'outil : https://colab.research.google.com
👉 Prise en main en 5 minutes : https://colab.research.google.com/notebooks/intro.ipynb

**4. VS Code et GitHub — pour la suite**
À partir de la séance 4, nous quitterons le navigateur pour écrire de vrais
projets : plusieurs fichiers, du code versionné, des tests. Nous les
installerons ensemble le moment venu — mais rien ne vous empêche de prendre de
l'avance dès maintenant :
👉 VS Code : https://code.visualstudio.com/download
👉 Git : https://git-scm.com/downloads
👉 Créer un compte GitHub : https://github.com/signup

## Demain

Nous nous retrouvons pour une première prise de contact : faire connaissance,
vérifier que chacun a bien ses outils, et régler ensemble les petits blocages

## Ce que nous attendons de vous

La formation est résolument tournée vers la pratique : l'objectif est que vous
soyez opérationnels rapidement, pas que vous accumuliez de la théorie.

La seule chose que nous vous demandons, c'est un peu de **régularité**. De la
motivation, tout le monde en a le premier jour — c'est la discipline qui fait
arriver au bout. De notre côté, nous sommes là pour vous accompagner, et nous
le faisons avec grand plaisir.
