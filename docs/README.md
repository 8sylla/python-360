## Ce que contient chaque guide de séance

Objectifs pédagogiques · déroulé minuté (théorie / pratique / pause) ·
concepts clés avec analogies · plan diapo par diapo · exercice socle +
corrigé commenté ligne à ligne · palier bonus pour les profils techniques ·
incrément du fil rouge · ressources vérifiées.

## Les 5 règles d'or de l'Arc 1

1. Jamais de jargon sans son analogie **dans la même phrase**.
2. Jamais plus de 8 minutes de live coding d'affilée.
3. L'erreur est le programme de la séance : en provoquer 2 à 3.
4. Tout exercice produit une **sortie visible**.
5. Exercice socle pour tous **+** palier bonus pour les profils techniques.
