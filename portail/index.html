Le programme

Les supports, séance par séance

Slides, notebook et corrigé sont mis en ligne au fil des semaines. Un bouton grisé veut dire « pas encore publié », pas « perdu ».

—

Aucune séance ne correspond à ce filtre pour l'instant.

Le parcours

Deux arcs. Le second se tient sur le premier.

Arc 1

La rampe de lancement

Séances 1 à 4. On apprend des instructions : variables, conditions, boucles, structures de données, fonctions et fichiers. Tout se passe dans le navigateur, il n'y a rien à installer.

Se termine par une vraie application en ligne de commande, dont les données survivent à la fermeture.

Arc 2

Structurer, puis analyser

Séances 5 à 8. On cesse d'apprendre des instructions, on apprend à organiser du code — puis à faire parler des données réelles avec NumPy, pandas et Matplotlib.

Se termine par un tableau de bord tiré de trois cents lignes de vraies données.

Le fil rouge

OpportuniTrack — un seul projet, six versions

Un suivi de bourses, stages et appels à candidature. Chaque version manque de quelque chose — et ce manque est exactement ce que la séance suivante vient réparer. On ne repart jamais de zéro.

  1. v0.1 une fiche affichée à l'écran
  2. v0.3 un carnet en mémoire… qui oublie tout en fermant
  3. v1 une application qui garde ses données
  4. v2 la même, refaite en objets, lisible par un autre
  5. v4 300 vraies lignes, nettoyées
  6. v5 un tableau de bord qu'on peut montrer

Les outils

Cinq, pas un de plus

Un compte Gmail ouvre les trois premiers. VS Code et GitHub n'arrivent qu'à la séance 4.

Google Classroom

Le cours : supports, devoirs, corrigés, et les questions entre les séances.

Google Meet

La séance en direct, trois heures par semaine. Le lien est dans Classroom et ne change jamais.

Google Colab

Écrire et exécuter du code depuis le navigateur, sans rien installer.

VS Code

À partir de la séance 4 : de vrais fichiers, de vrais projets.

GitHub

Le fil rouge, versionné — et le travail à plusieurs.

Participer

Il suffit d'un compte Gmail

  1. Rejoins le cours Classroomavec le code reçu par mail, puis dis bonjour dans le flux — ça vaut inscription.
  2. Ouvre Colab une foiset exécute un print("Bonjour"). Si ça s'affiche, tu es prêt·e.
  3. Teste ton casquemicro et son, dans une réunion Meet à vide. Le micro intégré fait de l'écho pour toute la salle.
  4. Remplis le questionnairedeux minutes. Il sert à composer les binômes.
