Les dunder methods

Python cherche
une prise.

Il ne demande pas « quelle est ta longueur ? ». Il cherche __len__. Si elle existe, len(objet) marche.

Le catalogue utile

Tu écris la prise, Python branche l'appareil.

__len__len(carnet)
__iter__for x in carnet
__eq__a == b
__repr__ce qui s'affiche dans le débogueur
Notes Règle pratique : si tu n'en écris qu'une, écris __repr__. Python l'utilise par défaut pour les deux, et c'est celle qui s'affiche dans les listes.

Le décorateur

Quatre marches. Aucune à sauter.

Formation Python 360° · ASEGUIM
Analogie

Un décorateur,
c'est un emballage.

Il enveloppe une fonction pour lui ajouter un comportement, sans toucher à son contenu.

Les quatre marches

C'est ce découpage qui fait la différence.

01

Une fonction est une valeur

f = dire_bonjour

02

Elle peut en recevoir une

def deux_fois(f)

03

Elle peut en rendre une

La marche difficile.

04

@ est du sucre

f = deco(f)

Notes Ne jamais sauter la marche 3. C'est là que se joue la différence entre « je copie » et « je comprends ». Y consacrer le temps nécessaire.
@chronometre
def chronometre(fonction):
    @functools.wraps(fonction)
    def enveloppe(*args, **kwargs):
        depart = time.perf_counter()
        resultat = fonction(*args, **kwargs)
        print(time.perf_counter() - depart)
        return resultat
    return enveloppe

Retire return resultat : la fonction décorée rend None et tout casse en aval.

Notes Provoquer les deux erreurs en direct : sans le return, puis sans functools.wraps (le nom devient « enveloppe »).
